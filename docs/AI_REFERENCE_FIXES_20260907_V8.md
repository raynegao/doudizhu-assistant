## 修改范围与证据

1. `src/vision/scene_recognizer.py`：原双端认证失败时，在既有 alignment 容差内补齐纸面首行之前的圆角端点候选。仍要求同一槽 x 的上下闭合，未调整阈值、补槽、删槽或重建标签。原 1153/1188 帧从几何未知恢复为 8 槽，候选框保持原坐标。
2. `src/tracking/visual_events.py`：新增有界的 `live_following_play_inferred_pass` 路径。只有最新 N 个递增源帧一致证明后续牌组、自己完整可信手牌未变、角色一致和精确余牌下降时，才用真实 reducer 预演 `pass → pass → play`，然后每次 update 最多提交一个事件。
3. 终局仍复用合法末手证明，不把消失的视觉余牌计数填成 0。新恢复链额外要求同一证据周期内的可信空场及原余牌数；第二次 pass 再检最新证据。几何/扫描证据周期水位与动作水位分离，阻止暂停前旧空场重送；缓存按 `max(6, 2*N)` 有界配置，覆盖非默认稳定帧数。

没有修改模型、模板、录制配置快照、参考标签、评测工具或门槛。新增测试：`tests/test_banner_hand_slot_extents.py` 16 项、`tests/test_double_pass_recovery.py` 103 项。

- 原图中横幅确实遮住部分 J 字形。几何计数恢复不代表完整牌点恢复：选定原帧的整手置信仍不满足输出建议条件，横幅消失后才用可信手牌和新出牌接回事件链。未用状态或标签填造 J。
